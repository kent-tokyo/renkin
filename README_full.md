# RENKIN reference

This former long-form README has been consolidated.

- Start with the concise [README](README.md).
- Use the [documentation site](https://kent-tokyo.github.io/renkin/) for
  installation, API, audit, MCP, and benchmark guides.
- Use [CHANGELOG.md](CHANGELOG.md) for versioned changes and
  [ROADMAP.md](ROADMAP.md) for repository planning.

The repository keeps measurement protocols and frozen results under
`docs/benchmark/` and `data/comparison/`. They are evidence records, not
product documentation; each result states its cohort, stock, budget, and
claim boundary.
